# Loja - Fake Store API

App em React Native + Expo + TypeScript, consumindo a Fake Store API (https://fakestoreapi.com).

## Funcionalidades

- Vitrine de produtos com busca por título e filtro por categoria
- Detalhe do produto com seletor de quantidade
- Carrinho: adicionar, alterar quantidade, remover itens e ver o total
- Estados de carregando, erro (com botão de tentar de novo) e lista vazia
- Troca de tela controlada por estado no App.tsx, sem biblioteca de navegação

## Como rodar

1. Clone o repositório e entre na pasta
2. Instale as dependências: npm install
3. Inicie o projeto: npx expo start
4. Escaneie o QR code com o app Expo Go, ou pressione `w` no terminal para abrir no navegador
